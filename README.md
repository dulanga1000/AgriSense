# 🌱 AgriSense - Smart Agriculture Mobile Application

AgriSense is a Flutter-based mobile application designed to assist farmers in making informed agricultural decisions. The application integrates AI-based disease detection, real-time weather updates, and smart recommendations to improve crop productivity.

---

## 📱 Features

- User Authentication (Login, Register, Forgot Password)
- AI-Based Crop Disease Detection
- Real-Time Weather Information
- Crop Advisory System
- Fertilizer Guidance
- Notifications & Alerts
- User Profile Management
- Multi-language Support (English, Sinhala, Tamil)
- Location-Based Services

---

## 🛠️ Technologies Used

- Flutter (Dart)
- Firebase Authentication
- Firebase Firestore
- Weather API (OpenWeatherMap or similar)
- TensorFlow Lite (TFLite)
- Provider / Riverpod (State Management)

## 🚀 Getting Started

1. Clone Repository  
git clone https://github.com/dulanga1000/AgriSense.git  
cd AgriSense  

2. Install Dependencies  
flutter pub get  

3. Run Application  
flutter run  

---

## ⚙️ Configuration

Firebase Setup  

1. Create Firebase project  
2. Enable Authentication (Email/Password)  
3. Enable Firestore Database  
4. Add:  
   android/app/google-services.json  
   ios/Runner/GoogleService-Info.plist  

API Configuration  

Update API keys in:  
lib/core/constants/api_constants.dart
